# Portal CT VOZ

Sistema web desenvolvido para auxiliar a gestão de uma academia de Jiu-Jitsu.

## Tecnologias

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Supabase
- Git

## Funcionalidades

- Login
- Controle de usuários
- Planejamento de aulas
- Escala de professores
- Avisos internos
- Responsividade

## Objetivo

Desenvolver uma aplicação utilizada no dia a dia da academia, facilitando a organização das aulas e da equipe.
